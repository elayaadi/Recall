# Recall

A retrieval-augmented generation system that answers questions from my own
study notes and course materials — markdown, PDF, and PowerPoint — with
citations back to the source passage, and a hand-built evaluation harness that
measures retrieval quality with real numbers.

**Status: in progress.** Repo scaffolding is in place; no stack has been chosen
yet. Architecture decisions are made one module at a time and recorded, with
their reasoning, in [SPEC.md](SPEC.md).

- [SPEC.md](SPEC.md) — module-by-module specification and decision record
- [CLAUDE.md](CLAUDE.md) — working conventions for this repo

This README is a placeholder. It is written properly in module 8, once there
are real evaluation results to report.
